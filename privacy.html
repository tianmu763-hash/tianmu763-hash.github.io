隐私政策

你选择频道并授权后，看板通过 YouTube Data API、YouTube Analytics API 和 YouTube Reporting API 读取频道及视频资料、发布信息、播放及订阅统计、缩略图展示和点击统计。只有你勾选收入权限时，看板才请求估算收入和广告表现。数据用于生成看板和经营报表。

授权凭据加密保存在部署设备上。看板在本地缓存数据以显示和更新报表。启用飞书同步时，频道及视频经营指标、报表日期和部署者设置的负责人标签会写入指定的飞书表格。授权凭据不会写入飞书。部署者管理看板和报表访问权限。

你可以在看板的频道管理中断开频道，或到 Google 账号的第三方连接撤销访问。断开后该频道停止同步。已导出的图片、CSV 和飞书报表由部署者管理。如需删除相应副本，请通过 OAuth 同意屏幕上的支持邮箱联系看板维护者。

本应用对从 Google API 获取的信息的使用和转移遵守 Google API 服务用户数据政策及其有限使用要求。
